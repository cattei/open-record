# open-record

一个**纯本地运行**的录音工具。点一下开始，点一下停止，录音文件自动存到你指定的目录。

没有云端、没有账号、不联网也能用。飞书远程控制是可选功能。

**无感设计**：第一次运行后自动设为开机自启，之后常驻右下角托盘，不占任务栏、不弹窗。
单击托盘图标打开界面，右键可退出。

---

## 为什么开源

市面上录音软件不少，但多数要么强制登录账号，要么录音上传到厂商服务器。
这个工具的设计前提是：**录音只留在你自己的电脑上**。

代码全部开放，你可以自己检查它做了什么。

## 快速开始

1. 解压整个文件夹（**不要只解压 exe 或 bat**，必须保留子目录）
2. 双击 **`启动录音助手.bat`**
3. 点「开始录音」说话，点「停止录音」
4. 录音文件在 `recordings\日期\` 下

无需安装 Python，运行时已内置在 `runtime\` 目录。

首次运行会自动写入开机自启（当前用户注册表，**不需要管理员权限**），
之后开机就静默驻留托盘，不再弹窗。

## 托盘常驻

| 操作 | 效果 |
|---|---|
| 单击托盘图标 | 打开界面 |
| 右键 → 显示界面 | 同上 |
| 右键 → 开始/停止录音 | 不打开窗口也能录 |
| 右键 → 开机自启 | 勾选/取消开机自启 |
| 右键 → 打开录音目录 | 直接跳转到录音文件夹 |
| 右键 → 退出 | **真正退出**（关闭窗口只是收进托盘）|
| 关闭窗口 | 收进托盘，录音不受影响 |

托盘图标颜色就是状态：**蓝色=待命，红色=录音中**。鼠标悬停能看到实时计时，
不打开窗口也知道录了多久。

> 想再打开界面：再双击一次 `启动录音助手.bat` 即可（单实例，不会启动第二份）。

## 界面说明

| 区域 | 作用 |
|---|---|
| 状态卡片 | 显示待命 / 录音中（含计时与实时电平）|
| 开始录音 | 开始录制 |

| App ID / Secret | 飞书应用凭据，填了才启用远程控制 |
| 开机自动启动 | 勾选后随系统启动（默认已勾选）|

> 录音进行中「保存并生效」会自动禁用——保存会重启服务，
> 而重启路径会丢掉正在写的录音。请先停止再保存。

## 飞书远程控制（可选）

想在手机上遥控电脑录音，可以配置飞书机器人。

1. 打开 [飞书开放平台](https://open.feishu.cn/)，创建企业自建应用
2. 记录 **App ID** 和 **App Secret**
3. 在「权限管理」开通：`im:message`（接收消息）、`im:message:send_as_bot`（发送消息）
4. 在「事件订阅」选择**长连接**模式，订阅 `im.message.receive_v1`
5. 把 App ID / Secret 填进本工具，点「保存并生效」
6. 在「版本管理与发布」创建版本并发布

之后在飞书里给机器人发「开始」「停止」「状态」「取消」即可。

> 不填 ID/Secret 时，程序**不会加载**飞书组件，内存占用更低。

## 录音参数

配置文件 `config.json`，改完重启程序生效。

| 键 | 默认 | 说明 |
|---|---|---|
| `recordings_dir` | `recordings` | 保存目录，相对路径相对程序目录，也可写绝对路径 |
| `prebuffer_sec` | 15 | 预录秒数。**仅在 `always_on_mic=true` 时真正生效**，否则待命不占用麦克风、无音频可预录（见下方说明） |
| `always_on_mic` | false | 待命期间是否常驻占用麦克风。false 时不占设备（其他软件可随时用），代价是预录失效；true 才真正预录 `prebuffer_sec` 秒 |
| `chunk_sec` | 30 | 分片时长，断电最多丢这么久 |
| `max_hours` | 6 | 单次录音上限，防止忘记停止占满磁盘 |
| `mp3_bitrate` | 192 | mp3 码率，48kHz 单声道。可选 96/128/160/192/256/320 |
| `keep_native_rate` | true | 保留设备原生 48kHz。设为 false 会降到 16k，不可逆 |
| `gain` | 12.0 | 软件增益倍数。麦克风声音小可调大，太吵可调小 |
| `exclusive` | false | true 为独占麦克风（其他软件不能同时使用）|
| `autostart` | true | 开机自启。界面和托盘菜单里也能改，一般不用手改这里 |

#### 关于预录：默认不占麦克风

待命时程序**不打开麦克风**，这样其他软件（会议、语音输入）随时能用，
不会被录音助手挡住。代价是点击「开始录音」到设备真正开流之间的声音
无法补录，实际只能并入约 0.2 秒。

如果你更在意「开口第一句不能丢」，把 `always_on_mic` 设为 `true`：
待命期间就保持开流并持续填充环形缓冲，点击后能真正并入 `prebuffer_sec` 秒。
**注意**此时麦克风会被常驻占用，其他软件可能无法同时录音。

## 关于转写

**本工具不做语音转文字。** 这是刻意选择，不是未完成的功能。

原因：本地 whisper 模型在普通麦克风录音上术语识别率只有 0-5%，
输出大量同音错字，实际不可用。与其给一个看起来能用但需要反复校对的结果，
不如不做。

需要文字稿，建议：
- 用本工具录音，再交给专业转写服务（如讯飞、剪映等）
- 或用系统录音机 + 厂商转写

代码中保留了转写模块（`app/asr.py`），
需要可以自行安装 `faster-whisper` 后开启 `transcribe: true`。

## 已知限制

| 限制 | 说明 |
|---|---|
| 录音电平偏低 | 笔记本内置麦克风远场拾音天生弱，已在解码时放大 12 倍补偿。若仍偏小，调 `gain` |
| 信噪比受限 | 远场录音噪声大，靠近说话效果更好；外接麦克风提升明显 |
| Windows 独占 | 仅支持 Windows（依赖 Windows 音频 API）|

## 常见问题

**Q：双击 bat 后窗口闪一下就没了？**

解压不完整。请确认 `runtime\python\python.exe` 存在。

**Q：关掉窗口程序就退出了吗？**

没有。关窗只是收进右下角托盘，录音服务继续运行。
要真正退出，右键托盘图标 → 退出。

**Q：怎么彻底卸载？**

右键托盘图标 → 退出，然后取消勾选「开机自动启动」，最后删掉整个文件夹。
（自启只写了一个注册表值 `HKCU\...\Run\ProjectRecord`，取消勾选即清除。）

**Q：托盘图标不见了？**

Windows 会把不常用的托盘图标收进「隐藏的图标」里（点任务栏的 `^` 展开）。
也可以在「设置 → 任务栏 → 其他系统托盘图标」里把它设为常显。

**Q：杀毒软件报警？**

本工具是 Python 打包，未做数字签名。若被拦，添加信任或检查源码后使用。
源码全在 `app\` 目录，可自行审计。

**Q：录音有杂音 / 听不清？**

先调大 `config.json` 里的 `gain`（如改 20），或用外接麦克风。
远场录音的物理限制无法用软件完全弥补。

**Q：能录多久？**

单次默认上限 6 小时（`max_hours`），到时自动停止。

**磁盘占用要按峰值算，不是只算成品：**

| 阶段 | 每小时占用 |
|---|---|
| 录音中（48kHz 单声道 int16 分片） | 约 330MB |
| 收尾后（192kbps mp3 成品） | 约 84MB |

分片在合并成 mp3 后立即删除，所以稳定占用是 84MB/h；
但**录音期间**峰值是 330MB/h。录 6 小时约需 2GB 临时空间。

程序不做自动清理，录多少留多少，请自行定期整理。

## 目录结构

```
open-record\
├── 启动录音助手.bat      双击启动（已在运行时则唤出窗口）
├── config.json           配置
├── app\                  源码
│   ├── launcher.py       入口（依赖自检）
│   ├── gui.py            界面
│   ├── config.py         配置默认值与深合并（唯一真源）
│   ├── miclock.py        跨进程麦克风互斥
│   ├── tray.py           右下角托盘图标与菜单
│   ├── autostart.py      开机自启（写 HKCU Run，免提权）
│   ├── singleton.py      单实例锁（避免开两份抢麦克风）
│   ├── recorder.py       录音采集
│   ├── merge.py          合成 mp3
│   ├── service.py        服务编排
│   ├── feishu.py         飞书通道（可选）
│   ├── asr.py            转写（默认不用）
│   └── assets\           图标（蓝=待命 / 红=录音）
├── packaging\            构建脚本（打包、生成图标）
├── tests\                回归测试（22 项断言）
├── runtime\python\       内置 Python 运行时
├── recordings\           录音输出
└── logs\                 运行日志
```
