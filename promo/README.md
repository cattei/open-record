# 宣传与介绍材料

这个目录专门存放**对外介绍录音助手**的材料。和 `docs/` 的区别：

- `docs/` 是给**开发者/使用者**看的技术文档
- `promo/` 是给**潜在用户**看的宣传材料，重点是「一眼看懂这是什么、怎么用」

## 先看这个

**想快速了解怎么用** → 打开 [`guide/使用指南.html`](guide/使用指南.html)

它是**单文件自包含**的（所有图片都 base64 内嵌），可以直接双击打开、发微信、发邮件，不会出现图片裂开。手机上也能看。

**想「看动画」式了解** → 打开 [`demo/index.html`](demo/index.html)

10 步交互动画：从双击启动、托盘图标、开始/停止录音、右键菜单，到飞书配置与校验失败。支持「自动播放」、上/下一步、点圆点跳转，键盘 ← → 翻页、空格播放/暂停。也是单文件自包含，双击就能看。

**想直接看视频** → 打开 [`demo/使用演示.mp4`](demo/使用演示.mp4)

55 秒，1600×900，H.264 / yuv420p——Windows 自带播放器、微信、手机都能直接播，不用装任何东西。内容与上面的交互动画是同一套 10 步，适合发群、发朋友圈、给不会用 GitHub 的人看。

**想改内容再重新生成** → 编辑 [`guide/使用指南.md`](guide/使用指南.md)，然后跑：

```bat
runtime\python\python.exe promo\assets\_tools\build_guide_html.py
```

会重新生成 `guide/使用指南.html`。

视频演示是两步（先抽数据，再合成；顺序不能反）：

```bat
runtime\python\python.exe promo\assets\_tools\extract_demo_steps.py
runtime\python\python.exe promo\assets\_tools\build_demo_mp4.py
```

会重新生成 `demo/使用演示.mp4`（1600×900 / 30fps / 约 55 秒 / 1.9MB）。
**依赖**：系统 Python（`C:\env\python\python.exe`）里的 `av`(PyAV, 含 libx264) 与 `Pillow`；
内置运行时 `runtime\python\` 没有这两个包，别用它跑。
改了 `demo/index.html` 的文案或聚光灯坐标后，重跑上面两步视频才会跟着变。

## 材料的三个层次

### 1. 一句话介绍

> 一个纯本地运行的录音工具。点一下开始，点一下停止，录音自动存到你指定的目录。
> 没有云端、没有账号、不联网也能用。

适合放在 GitHub 简介、群聊介绍、朋友圈第一行。

> 对外发布时**建议加一句限定**：「默认不联网；只有你主动开启飞书远程控制时，
> 发停止会把当次 mp3 上传到飞书服务器发回给你」。不加这句，开了飞书的用户
> 会以为录音只在本机——这不是小事，别省这半句话。

### 2. 一分钟版（看截图就懂）

配 `02-main-window-idle.png` + `03-recording.png` + `04-tray-menu.png` 三张图：

1. 双击启动，右下角出现蓝色麦克风图标
2. 点「开始录音」说话，再点「停止录音」
3. 录音存到 `recordings\日期\`，随时打开

### 3. 完整版

见 [`guide/使用指南.md`](guide/使用指南.md)，覆盖：

- 下载、解压、首次启动（含「为什么必须解压整个文件夹」这个高频坑）
- 录一段的完整流程 + 录音中界面变化
- 托盘图标怎么用、怎么真正退出
- 可选：接入飞书，用聊天控制录音
- 常见问题（找不到图标、没声音、磁盘占用、关窗口不退等）

## 截图是怎么来的（保证真实）

所有截图都是**程序真实运行画面**，不是画的、不是 P 的：

- 工具：[`assets/_tools/shot.py`](assets/_tools/shot.py)
- 做法：真实构造 `RecWindow`，真实点击按钮、真实开麦克风录一段、真实调用飞书接口
- 抓图：Win32 GDI 物理像素（2x DPI → 2880x1920 原图），保留原生标题栏
- 副作用：脚本 patch 掉了 `save_config` 和开机自启写入，**不会改用户的配置和注册表**

所以截图里的：
- 计时器数字是真的在跑
- 电平数字是真的麦克风电平
- `07b` 里的红字 `code=10003 invalid param` 是**飞书服务器真的返回的**
- 日志文字是程序自己写的

## 关于「一键创建飞书机器人」的准确说法

宣传时请注意**不要**写成「点一下就自动创建好飞书应用」。

事实是：**飞书开放平台没有提供创建应用的 API**（`lark_oapi` 的 application 资源里只有查询/更新，没有 create）。

所以这个按钮做的是：

| 自动化的部分 | 需要用户在网页上点的部分 |
|---|---|
| 打开创建页 | 点「创建企业自建应用」 |
| 复制应用名到剪贴板 | 粘贴应用名 |
| 列出必须开通的权限 | 手动开通两项权限 |
| 校验 App ID / Secret（真调接口） | 复制粘贴凭据 |
| 写配置、启用、建长连接 | — |

准确的说法是：**「除了在网页上点几下，其余全部自动化，并且会真的帮你验证凭据对不对」**。

## 维护约定

- 改界面后，重新跑 `shot.py` 出图，再跑 `build_guide_html.py` 重建 HTML
- demo 的聚光灯坐标是按截图的**实际像素**算出来的百分比（`left/top/width/height`），
  界面或截图变了必须重算，否则高亮框会框偏。重算方法见 `build_demo.py` 里的注释
- 截图目录里的文件名带序号，插入文档时按序号顺序
- 新增截图请同时更新本文件的「目录内容」和指南里的引用
